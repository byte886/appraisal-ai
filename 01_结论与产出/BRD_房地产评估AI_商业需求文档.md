## 1. 商业背景与机会（为什么是现在）

- **行业现状**：房地产估价报告（抵押、征收、司法处置、土地、租金、可研等）高度依赖人工"翻模板、查成交/地价/政策、套方法公式、写标准化段落、再做三级审核"。重复性填报与套话撰写占比高，但**结论与签字责任必须由持证估价师承担**（行业三级审核与签字制度，见竞品库 06）。【事实，依据行业规范 GB/T 50291-2015 等】
- **技术窗口**：2025 年起 Agent + 可插拔 Skill（SKILL.md+脚本）+ 本地知识库 RAG + 文档自动生成（python-docx 等）成熟，使"采集→测算→撰写→合规校验→成稿"能以低成本拼装；竞品已现场演示可研报告约 3 分钟成稿、评估作业多环节 Skill 化。【一方称：竞品培训现场截图 shot17–30】
- **需求侧信号**：合伙人所在的小型评估公司老板**正准备向 AI 转型**，提供真实业务、真实报告与试点意愿；合伙人同事已在通用 Agent（WorkBuddy）上自建 5 个技能并跑通"找实例→比较法测算→审核"最小链路，说明一线有强自驱需求。【事实：R11 同事实践；人物/公司对应待确认，ISSUES-001】
- **供给侧信号**：竞品（深圳房讯通「灵顾」）已把这套能力产品化并对外招商、报价、签意向书，证明市场已被教育、有人愿意付费。【一方称：竞品商务方案/意向书，R11】
- **为什么我们能做**：① 合伙人持房地产估价、土地估价、资产三证，具备领域规则、模板、审核口径与执业判断；② 开发具备产品/工程实现能力；③ 手握一家真实小机构作试验场，能拿到脱敏真实报告与即时反馈——"资质 + 工程 + 试验场"三者齐备，是纯软件团队或纯评估团队都不具备的组合。

## 2. 目标客户与场景（为谁做）

- **首批客户画像（SAM）**：三四线/区域市场（首站海口/海南）的**中小型房地产（土地/资产）评估机构**，10 人上下、报告类型以银行个贷抵押为主、兼有征收/司法/土地/租金；缺自研能力、对年费敏感、老板一两个人即可拍板。
- **使用人 vs 付费人（2026-09-16 澄清，见 ADR-002）**：**早期实际使用者只有两人——开发自己 + 估价师合伙人（自用提效，先让自己用好，暂无对外计划）**；一线估价师是产品化之后的使用人。付费/决策人=机构老板，但**试验场老板参训了解后当前不愿付费，仅为潜在客户**，不是本期用户或出资方；付费验证后置。
- **核心高频场景（尖刀，已一线确认）**：**个人住房/商业房地产抵押估价报告**——单量大、模板与方法（比较法为主、收益法为辅）相对标准、数据需求相对收敛。**【2026-09-16 合伙人确认】这也是公司量最多、时效要求最快（"要求要快"）的业务，尖刀选择获一线验证。**
- **痛点与现状代价**：单份报告大量时间花在查案例、算修正系数、套写市场背景与测算过程、排版与前后数字勾稽；新人培养慢、老手被重复劳动占用。具体单份耗时与人力成本**【待核实】**（请合伙人给现状基线，用于 G2 算节省比例与付费价值）。
- **付费意愿线索**：竞品已在收数万元/年级别费用（见第 3、5 节，**【一方称】**），侧面说明机构或有预算；但**试验场老板参训后当前不愿付费（2026-09-16 确认），仅作潜在客户观察**。近期不以"签约付费"为目标，先把两人自用的提效价值做扎实（见 ADR-002）。
- **首期不服务谁**：① 需要全国成交/地价大数据覆盖的全国性大客户与平台；② 追求大而全"AI 中台/智能体商店"的集团客户；③ 非评估主业的泛办公自动化需求。避免与竞品正面拼数据与平台广度。

## 3. 市场与竞品（战场长什么样）

### 3.1 市场规模（口径从严，数字待核实）
- TAM=全国房地产/土地/资产评估机构及其报告产出；SAM=海南及可触达区域的中小机构；SOM=首站海口可触达的数十家量级小机构。**机构数量、年报告量、客单价均【待核实】**，需求讨论阶段用行业协会/工商/黄页与合伙人经验给保守区间，不杜撰精确 TAM。
- 早期不追求大市场数字，而追求**单店经济模型成立**：一家机构用了之后，省的人力成本 > 付的费用，且能被第 2、3 家复制。

### 3.2 主要竞品/替代方案
| 对手/替代 | 是什么 | 收费（均【一方称】，R11 商务件） | 强项 | 弱项/我方机会 |
|---|---|---|---|---|
| 深圳房讯通「灵顾 AI」/云估价/估价宝/CAS | 垂直评估 AI 中台：Skill 工厂+MCP+本地知识库+多 Agent，网络端约 10 智能体、客户端约 10 Skill 模板，覆盖评估生产/招投标/可研/征收等 | 灵顾·AI ¥8万/3年（远程）；超级个体·领跑 ¥12万/3年（含赴深圳培训 2 名骨干）；Skills 定制按项目；会议口径另有 ¥4万/年、参会一次性 ¥6万/3年（**口径矛盾，ISSUES-002**）；宣称合同期 Token 全免 | 体系全、行业沉淀久、有数据/询价产品矩阵、已招商 | 重、贵、偏平台与培训；全国数据与中小机构本地数据有差距；贴身服务与本地化弱；价格对小机构偏高 |
| WorkBuddy「小迪」（腾讯系通用 Agent） | 通用办公 Agent，本地 SKILL.md+脚本，可自建技能 | 价格【待核实】 | 通用、灵活、同事已上手、比较法最小链路已跑通 | 非评估垂直：无数据底座、无装配、12 个方法引擎空缺、契约未统一、不能直接售卖为行业方案 |
| **人工 + Word 模板 + Excel（最大隐性对手）** | 现状做法 | 0 软件费，但=人力成本 | 灵活、合规责任清晰、零学习成本 | 慢、重复、依赖人、难规模化；这是真正要替代的"对手" |
| 其他 | 各地数据服务商、询价/CAS 平台、通用大模型直接问 | 不一 | 单点数据/通用能力 | 不成体系、不解决成稿与合规闭环 |

### 3.3 我方差异化（一句话定位）
> **"懂评估的人做的、为中小机构贴身落地的轻量 AI 出报告助手"——不卖给你一个大平台，而是先把你最高频的那份报告（个贷抵押）做到真能过审、真省时间，并能装在你自己电脑/本地知识库上、陪你跑顺。**

赢的维度：**垂直尖刀深度、本地/私有化与数据安全、可溯源合规、贴身陪跑与培训、低价轻量、依托持证估价师的领域可信度**。不赢（也不硬拼）的维度：平台广度、智能体数量、全国数据库、品牌与融资规模。

### 3.4 进入策略
**第一步（当前）：两人自用**——在合伙人真实项目里把个贷尖刀用到顺手、报告能过审、工时确实下降；**第二步（后置，暂无时间表）**：再以"真实省工时 + 过审样板"打动试验场老板（其当前不愿付费）及本地同类机构，做私有化陪跑/订阅复制。先深后广、先自用后产品、先验证提效再谈商业化。

## 4. 商业目标与成功指标（怎么算赢）

- **北极星指标（建议）**：**通过机构三级审核、由持证估价师签署的 AI 辅助报告累计份数**（同时代表真实可用与产能）；中期辅以"付费机构数 / 经常性收入"。
- **阶段指标**：
  - 验证期 G2（建议 2–3 个月内，日期待排）：个贷比较法样板线端到端跑通；产出 ≥3–5 份脱敏真实报告并过审；单份手工工时较基线降 ≥50%（目标 80%，**【假设】**待实测）；数值勾稽/合规零硬伤；试验场出现明确持续使用与付费意向。
  - 成长期 G3：签下 ≥1 个付费客户/付费试点；形成可复制交付手册；复制到第 2 家机构；客单价与续费口径明确。
- **止损线（No-Go，任一触发即停或转内部工具）**：
  1. 样板报告在真实三级审核中反复出现不能接受的硬伤、AI 产出需大面积返工，省不下时间；
  2. 试验场及 ≥3 家外部机构沟通后均无付费意愿（只愿免费用）；
  3. 合规/数据/签字责任无法在"AI 辅助 + 人工终审"框架下安全闭环；
  4. 单位经济为负且看不到下降路径（见第 5 节）。

## 5. 商业模式与盈利（怎么赚钱）

- **候选收费方式（早期组合，最终在 G2/G3 验证）**：
  1. **私有化/本地部署 + 实施陪跑费**（早期主推，契合小机构对数据安全与"有人教"的需求，按项目一次性 + 年费）；
  2. **机构订阅**（按账号/按年 SaaS，待产品标准化后）；
  3. **按报告份数/按报告类型包**（低门槛试用转化）；
  4. **定制 Skill / 模板与培训**（对标竞品"超级个体/定制"，做增值与获客入口）。
- **定价锚点**：竞品 ¥4万–12万/3年区间（**【一方称】**）显著偏高且重；我方早期可用"轻量 + 本地化 + 陪跑"定在中小机构更易决策的价位，并以"省下的人力成本"做价值锚。**具体定价【假设/待核实】**，需先摸清机构在报告上的人力成本与竞品真实成交价。
- **单位经济（待实测填表）**：单客年价值 −（Token/算力 + 实施陪跑人天 + 售后 + 获客）= 毛利；回本周期目标 < 12 个月（**【假设】**）。竞品把"合同期 Token 全免"当卖点，说明 Token 成本是客户敏感点，也是我方必须实测的变动成本（可研一份约 3 分钟成稿可作成本采样参考，**【一方称】**）。
- **成本结构**：固定=2 人开发/领域投入（主要是机会成本）、轻量服务器/存储；变动=模型 Token、数据源授权、实施与培训人天、售后。
- **获客渠道**：合伙人在行业内的人脉与公司样板、行业协会/培训班、本地银行入围评估机构圈层、"老板对老板"的转介绍；竞品靠招商会，我方靠真实样板与贴身口碑。

## 6. 解决方案概述与范围（高阶，功能细节归 PRD）

- **形态（按 ADR-002 调整）**：自用阶段**架构从简、以开发效率与成本优先**——云端、本地脚本、现成 Agent + 可插拔技能均可，怎么方便节约怎么来，**本期不做多租户、私有化安装包、机构权限体系与计费**；"本地/私有化、数据不出公司"保留为将来卖给机构时的能力选项与差异化卖点，不构成本期约束。6 大模块（详见需求池第 2 节）：M1 多类型报告模板库、M2 定向数据采集引擎、M3 评估公式计算引擎（核心）、M4 AI 智能撰写、M5 知识库与记忆、M6 一键导出报审 Word。
- **工作流**：选报告类型 → 录基础信息 → 自动采集+取公式+测算 → 填模板+AI 撰写 → 合规/勾稽校验 → **人工微调终审** → 导出正式报告。
- **本期做（尖刀）**：个贷抵押报告 + 比较法（收益法为辅）样板线；模板上传与占位回填；核心公式固化自动测算；定点数据采集与**来源留痕**；基础 AI 段落 + 合规校验；一键导出。
- **暂不做（防膨胀）**：招投标经营、**可研（合伙人判断实际做不到"3 分钟成稿"、公司或无此业务，非试验场需求；竞品演示视为"一方称"）**、征收、车辆/资产等全业务线（保留情报、后置观察）；全国数据平台；智能体商店；移动端、多人协作、自动取系数、第三方付费库（二期）。
- **关键依赖**：① 合伙人提供真实模板、数据来源清单、计算规则、审核规则（5 类交付物）；② 3–5 份脱敏真实个贷报告；③ 数据源的合规获取/授权；④ 试验场持续试点；⑤ 方法引擎清单经估价师重核（ISSUES-003）。

## 7. 投入与资源

- 人力：开发（产品/工程）+ 估价师合伙人（领域/规则/审核/试点；即 R11 中的国扬评估技术负责人"吴总"，本人受公司委托参训竞品），均兼职、每周可投入工时**【待估，Q6 待合伙人反馈】**；试验场老板=潜在客户、当前不付费不出资，本期不依赖其资源。
- 资金/工具：模型 Token、轻量服务器、必要数据源（金额待估，早期可控）；无大额固定资产投入。
- 时间：阶段一（定义）数周；G2 验证建议 2–3 个月（待排期）。
- 机会成本：为此推迟/放弃其他外包或项目；合伙人公司 AI 转型的注意力与试点成本。

## 8. 风险与合规

| 风险 | 说明 | 缓解/预案 | 致命性 |
|---|---|---|---|
| 签字/执业责任 | 评估报告须持证估价师签署并担责，AI 不能成为责任主体 | 明确定位"AI 辅助、人工终审"，AI 内容全部可改、留痕，不自动签发 | 高（红线） |
| 数据与个人信息合规 | 报告含产权人、房产、银行等敏感信息；自用阶段也在处理合伙人公司的职务数据 | 最小必要、**脱敏后再入系统/样本**、留痕；自用阶段云端可接受但不上传未脱敏件；商业化交付机构时再提供本地/私有化选项；遵循个人信息保护要求，注意职务成果与公司数据的使用边界（ISSUES-013） | 高 |
| 数据来源与可溯源 | 成交/地价/政策数据需权威、可回源以过评审 | 采集带来源链接/截图/查询时间；建数据源清单；不编造案例 | 高 |
| 专业正确性 | 方法/系数/规范用错会致报告不合格 | 规则来自持证估价师、方法清单重核、自动勾稽 + G1 市场区间/G2 合规双校验、人工终审 | 高 |
| 付费意愿 | 机构可能只愿免费用 | 早期用试验场验证价值与付费；按份/低价试用降低门槛；No-Go 线兜底 | 中高 |
| 竞品价格战 | 竞品宣称 Token 全免、体系全、招商早 | 不拼平台与免费，拼本地化、尖刀深度、贴身陪跑与持证可信度 | 中 |
| 数据底座缺失 | 我方/通用 Agent 均缺参数库/案例库 | 把数据底座当核心建设，先围绕个贷高频数据做小而准 | 中 |
| 知识产权/保密 | 仓内有付费竞品培训材料 | 仅内部研究参考，不抄袭不公开原件；仓库私有或脱敏（ISSUES-007） | 中 |
| 资源/持续性 | 2 人兼职、易被其他事打断 | 阶段门 + 轻量治理、聚焦尖刀、用 TASK_STATUS 控节奏 | 中 |

## 9. 结论与 Go/No-Go

- **结论：Conditional Go（带条件通过立项，进入阶段一深化与 G2 验证）。** 商业逻辑成立的关键在于"资质 + 工程 + 试验场"的稀缺组合与个贷尖刀的高频标准化；但**付费意愿、可替代工时比例、能否稳定过审、数据合规获取**四个核心假设尚未验证，不宜在验证前重投入做平台。
- 进入 PRD/开发前必须先验证的假设（即 G2 判据）：

| 关键假设 | 如何验证 | 可测量通过标准 | owner | 截止 |
|---|---|---|---|---|
| 个贷 AI 能稳定产出可过三级审核的报告 | 用 3–5 份脱敏真实报告跑样板线，合伙人按真实审核口径评 | 全部过审或仅余轻微人工修订；无勾稽/合规硬伤 | 开发+合伙人 | M2 |
| 单份报告显著省时 | 记录现状 vs AI 辅助工时 | 手工工时降 ≥50%（目标 80%） | 合伙人 | M2 |
| 客户愿付费（**后置门，本期不考核**，ADR-002） | 自用跑顺后再访谈试验场老板/外部机构（老板当前不愿付费，仅潜在客户） | ≥1 家明确付费/签试点 | 合伙人+开发 | 商业化阶段（非近期） |
