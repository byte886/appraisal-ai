# 决策记录 ADR-001 · 正式立项并确定"竞品逆向 → 尖刀自研"方向

- 日期：2026-09-16 ｜ 项目：房地产评估 AI 产品 ｜ 状态：Accepted

## 背景

- 团队 2 人：开发（用户）+ 持房地产/土地/资产三证的估价师合伙人；合伙人在海口一家小型评估公司任职，公司老板正准备向 AI 转型，提供天然试验场。
- 已付费参加竞品（深圳房讯通「灵顾 AI」/云估价）AI 落地培训并现场拍照逆向调研；另从多个渠道（得到大脑笔记、另一豆包会话、合伙人同事的 WorkBuddy 实践、竞品商务方案与意向书）汇集情报。
- 竞品已展示较完整的 AI 评估作业体系（Skill 工厂 + MCP + 本地知识库 RAG + 多 Agent；评估生产、招投标经营、可研等多条业务线），行业正处在"AI 替代手工填报"的早期窗口。

## G1 立项门自评

| 二元标准 | 结论 | 依据 |
|---|---|---|
| 战略对齐 ≥ 3 分？ | ✅ 5/5 | 直接对应团队创业方向与合伙人公司转型，资质+试验场+开发能力三者齐备 |
| 成功标准可量化？ | ✅ | 见 00 总纲第 2 节（报告份数、工时下降、过审、付费意向） |
| 活跃项目数 ≤ 7±2？ | ✅（待全局盘点） | 本项目为当前明确主线；本机尚未建立全局 PPM 台账，建议择期用 project-manager `portfolio` 盘一次 |

G1 结论：**Go（通过立项）**。

## 决策

1. 正式立为一个项目，按 project-manager 六槽位 + 治理骨架管理。
2. 路径选择：**先逆向拆透竞品全部业务线（产出 BRD + 12 份 PRD），再聚焦自研**；自研首战只打**个贷抵押评估报告**尖刀场景，在海口试验场做最小闭环验证（G2），不一开始铺平台/全国数据。
3. 产品原则：AI 替代约 80% 手工填报/查数/套公式/标准化撰写，**人工终审与签字责任不外包**；外部数据全程可溯源；数值强制勾稽；个人信息最小必要、脱敏留痕。
4. 竞争策略：**不拼平台广度与全国数据**，走"海口试验场 → 尖刀场景做深 → 轻量/私有化部署 + 贴身陪跑"的差异化路线。

## 备选（被放弃/推迟的）

- 方案 A：直接对标灵顾做"大而全"AI 中台（10+ 智能体、全业务线、商店）。放弃因为：2 人团队资源不足、数据底座与全国数据拼不过已规模化竞品、首期无法验证。
- 方案 B：只做内部提效工具、不产品化。推迟因为：试验场老板有转型/付费意愿，存在做成产品与对外复制的机会，先以产品目标推进、保留降级为内部工具的退路。
- 方案 C：基于 WorkBuddy/通用 Agent 搭技能而不做独立产品。作为**现状与过渡**保留（合伙人同事已跑通比较法最小链路，可借鉴其方法论），但通用 Agent 缺数据底座与装配、不构成可售卖的垂直产品。

## 后果 / 何时重新评估

- 聚焦个贷尖刀意味着招投标(B)、征收(D)、可研(E)等线先降级观察/后置；若试验场最痛的点其实在别处，需求讨论时据证据重排优先级。
- G2 若证伪"AI 能稳定过审 + 客户愿付费"，按 BRD 止损线 Hold/Kill 或退回内部提效定位。
- 竞品"Token 全免"等价格策略若持续，需在 BRD 商业模式中重估定价与成本。
