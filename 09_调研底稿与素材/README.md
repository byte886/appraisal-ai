## 素材处理铁律

1. 新素材先在《素材收件箱》登记 Rxx → 读全（长图切段、PDF 逐页、在线页用浏览器取全文）→ 分线归位 → 标证据等级 → 简短汇报。
2. 证据四级：**【事实】**（可核验/一手）/ **【一方称】**（厂商、培训、商务、同事 AI 推演等利益相关或未独立验证说法）/ **【待核实】** / **【推断】**。
3. 竞品报价、客户案例、效果数字一律先按"一方称"处理，未经独立核实不得写成我方事实。
4. 原始素材只读不改；提炼与结论写到竞品库/需求文档/PRD，不回写覆盖原件。
5. 含个人信息（手机号、账号、姓名）与付费培训资料，对外/入库前按项目 AGENTS 与 BRD 合规要求处理。
