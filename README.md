# 房地产评估 AI 产品 · 竞品逆向与自研

> 面向中小房地产评估机构 / 评估师的轻量化 AI 自动出报告产品。本仓是该项目的**调研、商业论证（BRD）与产品需求（PRD）工作区**。
> 状态：🟢 阶段一（逆向与定义） ｜ 立项：2026-09-16 ｜ 方法：project-manager（Charter + 六槽位 + 阶段门）

## 这是什么

团队 2 人（开发 + 持房地产/土地/资产三证的估价师合伙人，合伙人所在海口小型评估公司正拟转 AI，作为首个试验场）。
通过付费参加竞品（**深圳房讯通「灵顾 AI」/ 云估价**）落地培训做逆向调研，结合多渠道情报，先产出 BRD 与一套 PRD，再聚焦自研首个尖刀场景——**个贷抵押评估报告**的 AI 辅助生产，目标替代约 80% 手工填报/查数/套公式/标准化撰写，**保留人工终审与签字责任**。

## 怎么读（导航）

1. `00_项目总纲.md` —— 一页纸：目标、成功标准、里程碑、owner、治理、文件映射。
2. `01_结论与产出/` —— **BRD 商业需求文档**（为什么值得做、怎么赚钱、怎么算赢）；后续各份 PRD 放这里。
3. `02_决策记录/` —— ADR（关键决策与理由，含 G1 立项门自评）。
4. `03_进行中的任务/` —— TASK_STATUS（进度）、ISSUES（开放问题/待核实/Won't-fix）。
5. `09_调研底稿与素材/README.md` —— 底稿槽位映射。
6. `竞品情报库/` —— 竞品 00–09 结构化情报（身份战略、技术架构、业务 Skill 全景、平台 A/B、行业背景、商务合规、证据台账、可研专题）。
7. `外部渠道素材/` —— 按批次 Rxx 归档的外部原文（豆包会话、同事 WorkBuddy 资料、竞品商务 PDF/意向书等）。
8. `training_shots/` —— 竞品培训现场截图与逐批情报提取。
9. `我方产品需求_多渠道整合.md` —— 各渠道"我方产品该怎么做"的需求池（6 模块 MVP、评估师采集清单、硬约束）。
10. `素材收件箱_持续登记.md` —— 新素材流水登记（Rxx）。

## 证据与保密约定

- 情报区分 **事实 / 一方称 / 待核实 / 推断**；竞品商务与效果数据多为"一方称"，未独立核实。
- 本仓含**付费培训资料、个人联系方式与我方竞争策略**，公开范围见 ISSUES-007（默认建议私有或脱敏后公开）。
