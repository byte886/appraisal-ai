# 现场截图情报补录（第4批起，零散单张，持续追加）

## shot_30（2026-09-12）：灵顾AI中台 五层架构总图【事实·屏幕拍摄，极重要】

- 标题：**灵顾 AI 中台五层架构**；副标题："**横向是业务流，纵向是能力栈**"。

### 横向业务流（7+1环节，闭环）
立项 → 查勘 → 调研 → 测算 → 报告 → 复核 → 归档 → **知识沉淀**（知识沉淀为橙色，回流到数据层形成闭环）。
- 与国标11步对应：立项≈受理委托、查勘=实地查勘、调研=搜集资料、测算=方法测算、报告=撰写、复核=三级审核、归档；额外加"知识沉淀"——每次作业结束把成果沉淀回知识库（对应"知识资产化"）。

### 纵向能力栈（5层，自上而下）
| 层 | 组成（屏幕原文） | 解读 |
|---|---|---|
| 治理层（橙色，贯穿） | 身份权限 · 审计日志 · 审批门控 · 策略引擎 | 企业级安全合规，横切所有层 |
| 数据与知识层 | 项目库 · 报告库 · 案例库 · 政策库 · 模板库 | 五库；可研系统的政策/案例/模板库即此层实例 |
| Skill 层 | 资料清单 · 可比初筛 · 报告初稿 · AI 初检 · 知识问答 | 评估主流程的5个核心原子Skill |
| 智能体层 | 项目经理 · 估价师 · 复核人 · 风控 · 知识问答 | 按岗位角色设Agent（多Agent编排的落地形态） |
| 接入层 | 多模型网关 · 公有云/私有化/本地 · 统一 API | 多模型可切换、三种部署模式、统一接口 |

### 关键判断（推断）
1. 这是灵顾中台的**官方标准架构语言**，A0底座PRD应直接采用"五能力层 + 业务流闭环"为主骨架，四件套（Skill工厂/MCP/知识库/编排）是其中的实现机制。
2. **接入层明确支持"公有云/私有化/本地"** → 竞品也能私有化，我方"私有化差异化"需进一步落到"更轻、更贴身、本地陪跑"，不能只讲私有化。
3. **智能体层=岗位数字员工**（项目经理/估价师/复核人/风控Agent），印证多Agent按角色分工。
4. Skill层5个原子能力（资料清单/可比初筛/报告初稿/AI初检/知识问答）是**按作业环节切的核心Skill**，与18Skill（按业务线切）是两个视角，需在03交叉对照、不重复建设。
5. "知识沉淀"回流五库=其知识资产化的闭环机制，我方报告系统也应在归档环节自动沉淀案例/报告/模板。
