## 一、一句话结论

竞品 = **房讯通**（评估行业垂直 IT/SaaS 与数据龙头，云估价/估价宝/CAS 的开发方），它把自家 AI 落地成果做成企业级平台 **「灵顾AI中台」**（Skill工厂 + MCP连接 + 本地知识库 + 多Agent编排），对内重构评估生产与招投标经营，对外通过"总裁沙龙获客 + 智能体商店售卖 + 同行数据资产化"三层商业化。我方是 2 人团队（1 开发 + 1 三证估价师），**不在平台/数据/渠道上正面硬拼，走单点尖刀（个贷报告 MVP）+ 本地化深度服务**。

## 三、证据分级规则（全库强制，写 PRD 时原样继承）

| 标记 | 含义 | 使用规则 |
|---|---|---|
| 【事实】 | 屏幕截图可见、公开可查、或 ≥2 个独立来源一致 | 可直接作为竞品现状陈述 |
| 【一方称】 | 竞品口述/PPT 宣称，未经我方独立验证 | PRD 中必须写"竞品一方称"，不得当事实 |
| 【待核实】 | 信息不全、口径矛盾、或需补拍/外部查证 | 挂起，列入 08 清单，不脑补 |
| 【推断】 | 我方基于证据做出的分析、判断、建议 | 明确写"我方判断"，与竞品事实分开 |

**来源代号**：`S1/S2/S3`=三份得到大脑分享笔记；`shot_01~16`=现场截图；`行业调研`=公开检索（中房学 CIREA、国标等，来源见06）；`推断`=我方分析。
