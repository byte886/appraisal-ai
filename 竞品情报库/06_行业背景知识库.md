# 06 · 行业背景知识库（不懂评估行业先看这里）

> 用途：每份 PRD 第 1 节"业务背景科普"的统一取材处，面向不懂评估行业的开发/合伙人。行业事实来自公开检索（主要为中国房地产估价师与房地产经纪人学会，简称中房学 CIREA；国标 GB/T 50291-2015），属【事实·公开来源】；个别为【推断】已标注。

---

## 1. 行业定义与规模

- 房地产估价（房地产评估）：由有资质的专业机构和**注册房地产估价师**，对房屋/土地等不动产在某一时点的客观市场价值进行分析测算，出具**具法律效力、需估价师签字并盖机构公章**的估价报告。它是交易、银行抵押、司法处置、课税、征收补偿中的"价值定锚"环节。

| 指标 | 数值（公开口径） | 来源 |
|---|---|---|
| 估价机构数量 | 约 5600 家，其中一级资质约 1000 家 | 中房学 |
| 注册房地产估价师 | 约 7.1 万人（截至2024.11） | 中房学 |
| 从业人员 | 近 30 万人（估价师/查勘/商务/审核等） | 中房学 |
| 行业年营收 | 约 310 亿元（2023），六大类评估中规模最大 | 中房学 |

- 行业特征【推断】：机构多、单家普遍小（十几到几十人为主）、区域性强、人力密集、质量高度依赖资深估价师个人经验——这正是 AI"把资深经验复制成系统、降本增效"的切入口。
- 我方估价师持"房地产估价、土地估价、资产评估"三证，覆盖不动产+动产+资产，适配面比单一房估更广（车辆/设备/企业资产等也能做）。

## 2. 谁付费：客户结构

| 客户 | 典型场景 | 业务特点 |
|---|---|---|
| **银行（最大客户）** | 个贷（个人住房抵押）、对公（企业经营贷）押品评估、**贷后批量重估** | 量大、单价低、时效高，须先入银行入围名单再派单；走量基本盘 |
| 法院 | 诉讼/破产/强制执行中的房产、资产价值鉴定（司法鉴定） | 严谨、责任重、收费较高 |
| 政府 | 房屋征收补偿、课税评估、基准地价、城市更新 | 项目制、批量大（对应竞品征收线） |
| 企业/个人 | 交易、入股、资产重组、不良处置、车辆等动产评估 | 零散、品类杂 |

## 3. 标准作业流程 11 步（GB/T 50291-2015，理解 AI 切入点的关键）

```
1受理委托 → 2确定基本事项 → 3编制作业方案 → 4搜集资料 → 5实地查勘
→ 6选用方法测算 → 7确定估价结果 → 8撰写估价报告
→ 一审 → 二审 → 三审 → 9交付报告 → 10收费 → 11归档
```
AI 改造对照：搜集资料/测算→A1；撰写报告→A3；三级审核→A2；实地查勘→A2移动端产证识别；归档/经营→平台B与A4。**"写报告+三级审核"是人力最密集、也是竞品 AI 改造最集中的环节。**

## 4. 四大估价方法（AI 测算的业务逻辑底座）

| 方法 | 原理 | 适用 |
|---|---|---|
| 市场比较法（比较法，最常用） | 找近期成交的类似房产（可比实例），对交易情况/时间/区位/实物差异逐项修正后定价 | 交易活跃的住宅、公寓、写字楼、商铺、标准厂房 |
| 收益法 | 预测未来净收益（租金等），用资本化率/折现率折算现值 | 有稳定收益的商场、写字楼、酒店、出租公寓 |
| 成本法 | 重新购建成本 − 折旧损耗 | 新开发、极少交易、无收益的特殊房地产 |
| 假设开发法 | 开发完成后价值 − 后续成本/税费/利润，倒推地价 | 待开发土地、在建工程 |

- 规范要求有条件时**两种以上方法互相校核**。竞品把"市场背景/区位/比较法计算/收益法计算"拆成独立 Skill 再拼装，正对应这套方法体系。

## 5. 三级审核制度（A2 的对标对象，法定质控要求）

| 层级 | 审核人 | 主要审什么 |
|---|---|---|
| 一审 | 项目估价师/项目负责人 | 资料齐全、尽调到位、资料间相符、测算过程、文字排版页码 |
| 二审 | 部门经理/副总估价师 | 假设限制条件合理、方法选用、价值逻辑、同类价格平衡 |
| 三审 | 总估价师/总经理 | 终审、合规与执业风险把关、**签字盖章负责** |

- 竞品主张：AI 自动完成前两级的"字段匹配+数值逻辑+合规提示"，把一审二审三审压缩为"AI 审完→仅留人工三审"，单份 5-6 分钟→约1分钟【一方称】。**AI 不替代三审签字与法律责任**，这是行业铁律，我方产品必须守住。

## 6. 银行押品评估链路（理解"询价/复估"场景）

依据《商业银行押品管理指引》，押品估值分**银行内部评估**与**委托外部评估机构**两种；外部机构须先进银行入围/合作名单、多按规则派单。
1. 客户经理办贷款时先"**询价**"（问价，轻量、未必出正式报告），复杂的再出正式报告；
2. 评估机构接单→查勘→找案例→测算→报价/出报告；
3. 银行内部评估人员对外部报告审核确认，确定押品价值；
4. **贷后**按周期（每年、或价格波动超阈值时）**批量重估（复估）**。
- "询价"高频、低门槛、低转化，人工回成本高 → A1 用 AI 自动回价、超阈值(例30%)转人工；"贷后批量复估"对应 shot_01 押品批量复估系统（一次约500条）。

## 8. 机构组织架构与典型岗位（理解 A4 与平台B）

中小机构典型设置：业务/市场部（接单、商务投标）、评估部（查勘写报告，分条线）、审核/质控部（三级审核）、财务行政综合部。

| 岗位 | 职责 | AI 增强点 |
|---|---|---|
| 商务/业务员 | 找项目、投标、对接银行、合同续约 | 平台B：找标/写标书/合同预警 |
| 查勘员/助理 | 外勤拍照、收产证、录信息 | A2移动端识别、自动录入 |
| 估价师（最稀缺） | 选案例、测算、写报告 | A1核价、A3报告生成 |
| 审核人（一/二/三审） | 逐级质控 | A2智能审核 |
| 行政 | 维护资质/注册证、**协会业绩备案填报** | B2素材库、A4自动填报 |

## 9. 行业传统痛点（竞品与我方共同的立论点）

| 痛点 | 表现 | AI 解法 |
|---|---|---|
| 效率低、依赖资深人 | 复杂报告耗时长，资深估价师稀缺、培养慢 | A1/A3 固化经验 |
| 三级审核耗人力 | 每份5-6分钟以上，审核者多为资深骨干 | A2 |
| 低单价业务不赚钱 | 车辆、批量询价人工成本覆盖不了收费 | A3-2、A1自动回复 |
| 数据采集滞后 | 成交/挂牌/法拍/租金案例靠人工搜 | A1房探长/自动采集 |
| 投标内耗 | 招标部门3-10人，细节失误废标 | B1/B2 |
| 资质/合同易错 | 资质更新滞后致标书出错、银行合同漏续 | B2素材库、B3预警 |
| 通用AI不好用 | 通用大模型有幻觉、编造网站电话，达不到企业级稳定 | 行业专用Agent+私有知识库RAG |

## 10. 术语速查表

| 术语 | 通俗解释 |
|---|---|
| 估价/评估 | 有资质机构和估价师测估资产值多少钱并出报告 |
| 押品 | 银行贷款抵押物（多为房产），估值决定可贷额度 |
| 个贷/对公 | 个人住房贷款评估 / 企业经营性贷款评估 |
| 询价 | 银行先问价（轻量、未必出报告），高频低转化 |
| 复估/重估 | 贷后按周期或价格波动对押品重新估值，常为批量 |
| 实地查勘 | 到现场看房、拍照、核实状况 |
| 可比实例/案例 | 近期成交的类似房产，比较法的参照 |
| 三级审核 | 报告交付前一审/二审/三审逐级把关的法定制度 |
| 商务标/技术标 | 投标文件：商务标含报价资质公司材料，技术标含服务方案 |
| 法拍房 | 法院强制拍卖的房产，是重要价格数据源 |
| 不良资产/尽调(NPL) | 违约贷款形成的待处置资产；尽调=全面尽职调查 |
| 在建工程形象进度 | 在建楼盖到什么程度（地基/主体/封顶） |
| 可研报告 | 项目立项/投资/融资前的可行性研究报告（非评估报告） |
| 征收/确权 | 政府房屋征收；确权=核实房屋土地权属归属与面积 |
| 估价宝 | 云估价（房讯通）旗下评估机构OA/作业系统，竞品已打通 |
| CAS | 房讯通的银行押品询价系统 |
| Skill | 把一个可复用AI能力封装成最小单元，多个Skill拼装成完整业务 |
| 灵顾AI中台 | 竞品企业级AI平台（Skill工厂+MCP+本地知识库+多Agent编排） |
| MCP | 模型连接外部工具/业务系统的标准协议 |
| RAG/本地知识库 | 检索企业私有文档后再生成，用以减少大模型幻觉 |
