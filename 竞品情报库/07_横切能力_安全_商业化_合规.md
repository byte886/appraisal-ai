## 1. Skill 切片拼装开发法（竞品最值得抄的工程方法）

- 【一方称·S3】完整报告/业务拆为独立小 Skill，单独开发调试，再自由拼装组合成不同类型报告/业务，跨类型复用、避免重复开发。
- 【事实·截图实证】两层证据：
  - shot_16/09专题：报告按**章节**拆模块文件夹（位置境域/政策检索…），公共章节沉淀复用；
  - shot_20~22：后台把 Skill 分"**报告生成 Skill（feasibility-report，ZIP+SKILL.md 可插拔）**"与"**公共章节 Skill（可多选绑定、逗号分隔）**"，报告类型靠"模板+输入卡片+占位符json+章节勾选"派生。
- 【推断·我方做法】①能力按最小可复用单元切分；②公共部分（区位/市场/政策/排版）只做一处；③引擎与业务包解耦，新增品类=换模板+配置，不重写引擎。

## 2. "零基础/低代码"的真实边界（校准预期，重要）

- 【一方称·S3】非技术人员（含50多岁董事长）2-4周即可搭出复杂业务系统，自然语言交互、无需写代码。
- 【事实·截图反证】复杂报告 Skill 底层是 **Claude Code（.claude）/ OpenAI Codex CLI（gpt-5.6-luna、YOLO模式）/ Cursor + Python 工程**（shot_16/17-19），现场仍在调试、有模型404和命令报错。
- 【推断】真实分层：**业务人员**用现成平台 + AI 编程助手搭"轻量小工具"（押品复估、字段映射、文件分类，见04-A4）确有可能；**复杂生产系统**仍需开发用 AI 编程 Agent 工程化搭建。对外宣传的"零代码"是简化叙事，我方对内规划不要按"完全不用开发"排期。

## 3. 成熟度与质量口径（竞品自陈，较客观）

- 【一方称·S3】通用场景 AI 成稿 **70-80 分**，满足银行类常规交付，**达不到行业评审满分**；不追求 100% 替代，标书/报告走"80% 自动 + 20% 专业内容人工"。
- 【一方称】岗位至少 20-30% 重复工作可自动化，优先改投入产出比最高的场景。
- 【事实】已知错误：B2 标书曾因 AI 幻觉自动生成**过期估价师合同**（S3）；A3-5 在建工程被安全网遮挡会识别错（S2）；可研生成遇模型404需重试（shot18）。
- 【推断】我方质量策略：不追"全自动"，把"来源可回源、数值可复算、错误可发现、人工必审20%、留痕可追溯"做成可信卖点。

## 4. 数据安全与核心资产隔离

- 【一方称·S3】Skill 是核心知识资产，采用"**服务端部署 + 员工仅调用结果**"模式，员工拿不到 Skill 本体、API Key、知识库，防外泄。
- 【一方称】**API Key 集中管控**，避免 Token 成本失控；头部用户单月 Token 费用可达十几万元【S3】。
- 【事实·shot_08】本地知识库/私有 RAG 主打"数据不出企业、回答基于真实业务数据、告别幻觉"；shot_10 提"统一AI入口、统一数据安全、灵顾+AgentDock硬件底座"。
- 【一方称·S3】自动收集员工使用问题，反哺 Skill 迭代（C-6）。
- 【推断·我方】2人/小机构阶段：API Key 服务端统一保管与额度告警；报告模板、测算规则、案例库作为核心资产分层授权；对外交付优先支持**私有化/本地部署**（中小机构对客户数据外泄敏感，这是相对大厂SaaS的差异化）。

## 5. 技术栈盘点（确定程度分级，详见02第6节）

## 6. 商业模式（三层结构）

1. **对内降本**：压缩评估生产与投标经营人力，让低单价业务（车辆、批量询价、县域可研）重新可盈利；数据团队70→5/10、研发40→6、全员200→70（均【一方称】，口径矛盾见01-7）。
2. **对外卖工具（SaaS/平台）**：灵顾AI中台/智能体商店，向同行机构卖现成行业 Skill；网页端付费使用、客户端开发调试；Skill 可上架收费（A0-4）。
3. **生态与数据变现 + 培训获客**：支持同行把**自有数据资产封装成智能体上架**分成；通过付费"总裁沙龙/训练营"完成获客与行业影响力（我方正是付费参会方）。
- 【推断·我方竞争策略】不在平台/商店/全国数据层面与其正面竞争；以"海口本地小机构试验场→打磨个贷等尖刀场景→轻量化、私有化、陪跑式服务周边中小机构"切入，用三证专业度+可信质量+贴身服务差异化。

## 7. 合规红线（竞品特别强调，我方必须前置设计，不可照搬灰色操作）

- 【一方称·S3，我方认同】爬取政府/公开网站数据**必须限速**；暴力高频爬取致目标网站崩溃，可能涉嫌**破坏计算机信息系统罪（刑事风险）**。
- 公开数据、客户合同、报告案例对外使用前必须**脱敏**（对应 B3-3 AI脱敏、按权限分发）。
- 【推断·补充】还需注意：①评估报告具法律效力，AI 仅辅助、**签字责任在估价师**，产品不得宣称"AI替代签字/无需估价师"；②客户房产/身份信息属个人信息，采集存储受《个人信息保护法》约束，最小必要、授权、留痕；③第三方数据（二手车平台、招投标平台、地图）使用遵守其条款与robots/协议；④AI生成内容建议标识、过程留痕以备执业检查。
- 【事实·可研系统佐证】其知识库设"审核记录/待审核/通过"机制（shot29）、政策来源到具体条例——合规与可回源是行业刚需，我方应内建审核流与来源标注。
